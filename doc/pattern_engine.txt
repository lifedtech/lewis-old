LEWIS — Composite Indexes & Pattern Engine
Purpose:
 The layer that turns nine dimension scores into a 
connected picture
 — composite indexes, texture patterns, and modulating layers. It sits between Layer 3 (scores) and Layer 5 (report), and its one job is to 
explain how dimensions relate, never to diagnose why one is low.
Governed by the Scoring Constitution.
 Two rules dominate this layer:
Reflective, never clinical.
 Internal engineering IDs may be technical; every 
output label
 a person could ever see is warm, plain, and non-diagnostic. No pattern names a condition, a hormone, or a cause.
Connection, not causation.
 A pattern says "your energy looks tied to how your body's been resting" — never "your low energy is 
because of
 X." The leverage estimate is "where effort goes furthest," not a root cause.

GROUP A · Composite indexes
1 · LWI — "Your overall reflection"
Field
Spec
Purpose
One gentle whole-life reading, immediately qualified by its spread — never a wellness "grade."
Variables
the nine final dimension scores + their confidences; WHO-5 overall + SWLS (sanity)
Formula
LWI.mean = mean(9 scores)
; 
LWI.spread = {min,max,sd}
; 
LWI.shape
 from spread
Weighting
equal weights
 (v1, transparent); a confidence-weighted shadow runs for QA only
Output label
band word only (Running on empty / Under pressure / Steady / Strong) + a spread line
Confidence
measurement
; system-confidence rollup; large |mean − WHO5·4| ≥ 15 → "early read" frame
Report
opens the report, then immediately names the shape: "steady overall — with two areas asking for attention"
Recommendation
does 
not
 drive recommendations (leverage does); sets whole-report compassion
Safety
all-low (Depleted Field) → gentlest framing + safety reinforcement
def lwi(scores, confs, who5_overall):
    mean = avg(scores); sd = stdev(scores)
    shape = "even" if sd < 12 else "uneven"          # uneven → a strength + a struggle coexist
    sanity = abs(mean - who5_overall) >= 15
    return {"mean":mean, "band":band(mean), "spread":{"min":min(scores),"max":max(scores),"sd":sd},
            "shape":shape, "sanity_flag":sanity, "confidence":"measurement"}
Example
 — nine scores (21,72,47,83,84,80,75,79,70): mean 
66.8 → Steady
, sd ≈ 18 → 
uneven
 → report says "steady overall, but your body and energy are asking for care." Sanity: |66.8−52|=14.8 < 15 → holds.

def recovery_load(cum_raw, recovery):
    load_n = cum_raw/30
    rf = {"recovered":0,"somewhat":.33,"still_tired":.66,"anxious_at_rest":1.0}[recovery]
    idx = 0.6*load_n + 0.4*rf
    label = "Light load" if idx<.34 else "Moderate load" if idx<.66 else "Carrying a lot"
    return {"label":label, "index":idx, "confidence":"reflection",
            "contra_high_commitment": (label=="Carrying a lot" and rf>=.66)}

0.6·.57+0.4·1.0 = .742

Carrying a lot
 → high-commitment programs gated out, down-regulation first.

def purpose_in_pain(priority_rank, scores, confirmed):
    cands = [(d, prio_w(priority_rank,d)*low(scores[d]))
             for d in dims if rank_top3(priority_rank,d) and scores[d]<55]
    if not cands: return None
    d,strength = max(cands, key=lambda x:x[1])
    firmness = {"Yes":"plain","Partly":"soft","Not quite":"withhold"}[confirmed]
    return {"dimension":d, "strength":strength, "report_firmness":firmness}

    base = {"7day":3,"one_thing":2,"overwhelmed":1}[planner]      # stack size
