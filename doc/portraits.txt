Rationale.
 A precise "62nd percentile" invites ranking anxiety and false precision the data can't bear; a coarse "around the middle, for people in a similar stage" gives orientation without a verdict. Suppress-never-fake holds: a thin cell yields a band, not a guessed percentile.
def position(score, cell, corpus):
    dist, N = corpus.distribution(cell)              # walks the fallback ladder internally
    if N < 30: return {"bucket": None, "shown": False, "reason": "thin_cell"}
    pct = percentile(score, dist)
    bucket = "lower range" if pct < 33 else "around the middle" if pct < 67 else "higher range"
    tag = "stable" if N >= 100 else "early_estimate"
    return {"bucket": bucket, "shown": True, "cell_used": dist.cell, "confidence": tag}

, stable. Report: "your physical reserves are in the lower range for people at a similar stage — and that's exactly where a small change pays off most." (Orientation, not a grade.)

PORTRAITS = [depleted_field, carrying_a_lot, low_tank, crossroads,
             connected_at_distance, holding_together, resourced_stretched, steady_ground]
def state_portrait(scores, patterns, lwi, safety):
    for p in PORTRAITS:                              # priority order; safety-first
        if p.entry(scores, patterns, lwi, safety):
            return {"id": p.id, "label": p.label, "opening": p.opening(scores, patterns),
                    "is_state_not_type": True, "traceable_to": p.evidence(scores, patterns)}
    return steady_ground.as_default()

PART C · Leverage coherence + disclosure gating
C1 · Leverage coherence
Cross-check the computed leverage point against the person's 
felt
 sense before the report speaks it firmly.
def leverage_coherence(leverage, gestalt_gap, priority_tension, tension_confirmed):
    agrees_felt   = gestalt_gap[leverage.primary] < 20            # their sort agrees it's low
    agrees_valued = priority_tension and priority_tension.dimension == leverage.primary
    if tension_confirmed == "Not quite": return "soften"          # they disagreed → offer, don't assert
    if agrees_felt or agrees_valued:     return "plain"
    return "offer"                                                # computed but unconfirmed → invite
plain
 — "your body is where effort goes furthest right now."
offer/soften
 — "this 
may
 be where it starts — does that land as true?"
C2 · Disclosure gating (what the report may assert)

def disclosure_plan(enriched):
    plan = {}
    for d, dim in enriched.dimensions.items():
        plan[d] = "assert" if dim.confidence>=0.75 else "offer" if dim.confidence>=0.50 else "withhold"
    for p in enriched.patterns:
        plan[p.id] = "state" if p.confidence=="measurement" else "gentle_reflection"
    for f in enriched.safety.fired():
        plan[f] = "assert"                          # safety cannot be down-ranked
    plan["leverage"] = enriched.leverage.coherence  # plain | offer | soften
    return plan
