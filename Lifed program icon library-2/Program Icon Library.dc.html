Lifed Design System · Program pages

Program page icon library

One icon per meaning, across every section of a program page. Two program types share the same set: icons marked teal are Day Program only, leaf are Residential only, and unmarked icons are used by both.

Program type mark

Day Program

Sessions only, no overnight stay. The sun over a horizon line reads as a single day, bounded start to finish. Teal is its accent colour throughout the page.

Type badge Meta bar Booking panel Search cards Review chips
Program type mark

Residential Program

Stay-inclusive, one or more nights on site. The same roofline as the day mark, with a moon held inside it: the program continues after dark. Leaf is its accent colour.

Using the set

Sizes

Four steps only. Anything larger than 28px is a program-type mark, not an icon.

{{ s.svg }}
{{ s.px }} {{ s.use }}

Colour

Icons inherit text colour. Teal marks the active or branded state; leaf is reserved for residential.

{{ c.svg }} {{ c.l }}{{ c.hex }}

Do

  • ✓Pair every content icon with a text label.
  • ✓Keep one meaning per icon across the whole catalogue.
  • ✓Align icons optically to the first line of text, not the block.
  • ✓Use the 44px tinted tile when an icon leads a list row.

Don't

  • ✕Mix filled or duotone icons into the line set.
  • ✕Use a medical or clinical symbol on a non-clinical program.
  • ✕Show a residential-only icon on a day program page.
  • ✕Scale strokes with the icon — stroke stays 1.7px at every size.
